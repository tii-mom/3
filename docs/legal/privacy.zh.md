# 隐私政策

最后更新日期：2026 年 9 月 12 日

感谢您使用 3API（以下简称"本服务"）。我们深知个人信息对您的重要性，并会尽力以审慎、最小化的方式保护您的隐私。本政策说明您在使
用 AI 代充值、成品账号及 API 中转服务时，我们如何收集、使用、存储与保护您的信息。

## 一、我们收集的信息

### 1. 账号与身份
- 注册或登录时提供的邮箱、手机号；
- 为完成风控与安全保障所必需的验证信息。

### 2. 订单与支付
- 您选择的商品规格、下单记录与订单状态；
- 支付由支付宝等第三方支付机构处理，我们**不存储您的银行卡号、密码或支付密码**，仅保留支付流水号、金额、支付状态等必要凭证用于对账与售后。

### 3. 服务履约所需信息
- 代充值或账号交付时，您主动提供的 ChatGPT 账号会话凭证（session）或账号信息，仅用于完成您所购买的服务，绝不会用于任何其他目的；
- API 中转产生的调用日志（调用模型、Token 用量、调用时间），用于计费、排障与风控。

### 4. 技术与安全信息
- 设备型号、IP 地址、浏览器类型、访问时间，用于安全防护、反欺诈与体验优化。

## 二、我们如何使用信息
- 履行订单、交付商品与服务；
- 处理支付与出具凭证；
- 提供客户支持与售后服务；
- 风控、反作弊与安全保障；
- 优化产品与服务（不会用于骚扰式定向广告）。

## 三、信息的存储与安全
- 传输与存储均采用加密措施；
- 账号凭证等敏感信息仅在履约所必需的时间内访问，完成后按最小化原则及时清理；
- 采取访问控制、日志审计等措施，防止未授权访问、泄露或篡改。

## 四、信息共享
- **我们不会出售**您的个人信息；
- 仅在完成交易所必需的范围内，向支付机构（如支付宝）提供最小必要信息；
- 当法律法规要求，或为保护本服务及其他用户安全时，我们可能依法向有权机关提供相关信息。

## 五、您的权利
您可随时：
- 查询、更正您的账号信息；
- 申请导出或删除您的个人数据（法律另有留存要求的除外）；
- 撤回非必要的授权同意。

如需行使上述权利，请通过本站客服渠道联系我们。

## 六、Cookie 与同类技术
我们可能使用 Cookie 等技术维持登录态与安全防护。您可在浏览器设置中管理或清除相关 Cookie。

## 七、未成年人保护
本服务主要面向成年用户。我们不会主动收集未成年人的个人信息；如发现有未成年人使用，将按最小化原则处理并视情况联系监护人。

## 八、政策的更新
我们可能不时更新本政策。涉及重大变更时，会通过站内公告或站内信通知；更新后以最新版本为准。

## 九、联系我们
如对本政策有任何疑问，请通过本站客服渠道与我们联系。

> 提示：本政策为通用模板，正式发布前建议由专业法律人士结合业务实际进行合规审查。
