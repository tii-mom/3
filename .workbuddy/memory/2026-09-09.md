## 3API 官网首页改版：API 中转站 → GPT 充值 / 成品号销售页

### 现状盘点结论
- 首页 = `frontend/src/views/HomeView.vue`（1481 行，路由 `/`，独立全屏落地页，不套 AppLayout，后台 `home_content` 可覆盖）
- 已有现成能力：商城表 `shop_products/shop_banners/shop_orders`（迁移 198_shop_commerce.sql，raw SQL 实现）、`/shop` API、用户端 `ShopView.vue`、后台商城管理与发货、支付渠道（alipay/wxpay/stripe/airwallex，EasyPay 等）、TurnstileWidget.vue
- 三个硬缺口：
  1. `internal/server/routes/shop.go` 全部挂 JWT → 首页无法免登录下单
  2. `shop_orders` 无字段存用户提交的 Session / 联系方式
  3. 商品无「下单表单」配置能力，无免登录查单入口
- 参考站 https://www.chong-zhen.com/ 结构：Hero → 服务亮点 → 选套餐（Plus 148 / Pro5x 800 / Pro20x 1380）→ 三步流程 → 服务保障 → 用户反馈 → FAQ → CTA

### 已拍板决策（用户确认）
- 下单门槛：**免登录直充**（新增公开下单接口）
- Session 提交时机：**支付后提交**（非我推荐的支付前；需在成功页做即时校验+允许重提来兜底）
- 成品号交付：**后台人工发货**（不做自动库存池）
- 定价：**全部从后台商城商品读取**，前端不写死
