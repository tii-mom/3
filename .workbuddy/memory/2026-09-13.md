### 1. 标题被英文 meta 覆盖（根因，影响全部路由）
`App.vue:28` 先 `document.title = resolveRouteDocumentTitle(...)`（走 `titleKey` 本地化），
**紧接着 29 行 `updateRouteSeo(route)` 用 `route.meta.title` 又覆盖回去** → `/login` 变 "Login"、
控制台各页都退回英文静态 meta。修法：`updateRouteSeo` 只在**首页/SEO 落地页**写 `document.title`，
其余路由不再覆盖（`og:title` 回落用当前 `document.title`）。另给 `/legal` 路由补 `titleKey: 'legal.documentTitle'`。

### 2. twitter:card 降级
`seo.ts` 硬编码 `summary`，把构建期注入的 `summary_large_image` 盖掉 → 改为 `summary_large_image`。

### 3. 图标 / manifest
用 Playwright + 系统 Chrome 把 `logo.svg` 渲染成 PNG，再手写 ICO 容器打包：
- `favicon.ico`（16/32/48，PNG-in-ICO，`file` 校验通过）
- `apple-touch-icon.png`（180，**直角满幅**，iOS 自己切圆角，避免透明圆角出锯齿）
- `icon-192.png` / `icon-512.png`（圆角透明）+ `icon-maskable-512.png`（满幅 + 字形收进安全区）
- `manifest.webmanifest`（standalone / theme_color #f97316）
- `index.html` 挂 `icon` + `apple-touch-icon` + `manifest` + `theme-color`。
  注：`vite.config.ts injectBranding` 是 `apply:'serve'`（仅 dev），不会抢这几个 link。
