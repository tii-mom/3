### 两个已踩并修复的坑（重要）
1. **Vue scoped CSS 中 `:global(.dark) .foo` 会被编译成只剩 `.dark`** → 深色规则静默失效。
   正确做法：**追加一个不带 `scoped` 的 `<style>` 块**，选择器直接写 `.dark .foo`。
   （项目里 `SettingsView.vue` 已有同样注释，是对照先例。）
2. **落地页类名与 `src/style.css` 的 `@layer components` 全局类撞名**：`.switch` `.table` `.btn`
   `.skeleton` `.card` `.badge` `.input`。scoped 只防外泄、不防外进。
   例：`.switch` 被全局样式当成 44×24 开关，导致首页分段控件塌陷成竖排。
   → 落地页统一改用 `sh-` 前缀（`.sh-btn` / `.sh-tabs` / `.sh-table` / `.sh-card` / `.sh-badge` / `.sh-skeleton`）。
   注意批量重命名时 `\btable\b` 会误伤 HTML 标签 `<table>`，需回改。
